# Shadow Flap: Product Purpose

## Target Audience
Shadow Flap is designed for the modern arcade enthusiast who values high-skill, low-friction gaming experiences.

- **Demographics:** Gen Z and Millennials (13-35) who enjoy retro-inspired visuals and challenging mechanically-driven gameplay.
- **Interests:** Retro aesthetics, synthwave/dark-electro music, speedrunning, and competitive high-score chasing.
- **Pain Points:** 
  - Saturated market of low-quality "hypercasual" games with intrusive ads.
  - Lack of mechanical depth in common "flappy" clones.
  - Desire for short, intense bursts of gameplay that fit into busy schedules.

## Value Proposition
Shadow Flap redefines the silhouette arcade genre by combining visceral visual feedback with unpredictable mechanical shifts.

- **Unique Portal Mechanics:** Unlike static clones, Shadow Flap introduces active "Modes" (Mirror, Split, Gravity) triggered by portals, forcing players to adapt their muscle memory in real-time.
- **High-Fidelity "Low-Fi" Visuals:** A professional silhouette art style using high-contrast neon accents and generative particle effects to create a moody, immersive atmosphere.
- **Competitive Fair Play:** The Daily Track system uses seeded randomization to ensure every player globally faces the exact same challenge each day, creating a legitimate level playing ground for competition.

## Core Feature Roadmap (Must-Haves)
1. **Dynamic Physics Overhauls:** Portal-based state changes (Split, Gravity, Mirror).
2. **Generative Obstacle Pacing:** AI-driven monster patterns that scale with player performance.
3. **Daily Global Competition:** Seeded tracks with daily leaderboard resets.
4. **Immersive Audio Engine:** Dynamic BGM that reacts to game intensity.
5. **Skill Scaling:** Three-tier difficulty system (Easy, Medium, Chaos) to cater to all player levels.
